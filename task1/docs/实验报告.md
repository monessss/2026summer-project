本实验检测键盘、农夫山泉瓶和手机三类桌面物体。系统使用 YOLO26n 完成目标检测，在 Jetson 上显示类别、检测框、置信度和 FPS，并通过 ROS2 话题 `/yolo/detections` 发布 JSON 检测结果。

## 4. 模型与训练方法

初始模型固定为 COCO 预训练的 `yolo26n.pt`。Nano 规模用于降低 Jetson 推理延迟；训练采用迁移学习，不从随机参数开始。

| 参数 | 数值 |
|---|---:|
| 模型 | `yolo26n.pt` |
| epochs | 100 |
| batch | 16 |
| imgsz | 640 |
| optimizer | AdamW |
| lr0 | 0.001 |
| lrf | 0.01 |
| weight decay | 0.0005 |
| cosine LR | true |
| patience | 30 |
| seed | 42 |
| deterministic | true |
| AMP | true |

数据增强固定包括 7° 旋转、0.08 平移、0.30 缩放、2° 剪切、HSV 扰动、50% 水平翻转和 50% Mosaic；最后 10 个 epoch 关闭 Mosaic。完整参数以 `configs/train.yaml` 为准。YOLO26 检测头不使用 DFL，因此报告不记录 `dfl_loss`。

正式训练于 2026-08-31 完成，使用 Python 3.10.19、Ultralytics 8.4.135、PyTorch 2.13.0+cu126 和 NVIDIA GeForce RTX 4060 Laptop GPU。训练耗时 0.170 小时；最佳权重来自第 93 个 epoch。最终发布文件为 `models/best.pt`，大小 5,371,141 字节，SHA-256 为 `7ab7a1cf4c08e2eb803d5666a6caa6931256cfabfe04dc8e9c98385322fbcdcf`。最佳权重在验证集上的结果为 Precision 0.863、Recall 0.848、mAP50 0.884、mAP50-95 0.695。

## 5. 独立测试集评估规则

训练完成后，`src/evaluate.py` 只使用 `test` 划分，生成 `metrics.json`、混淆矩阵、PR/F1 曲线、错误清单和错误图片。报告采用 `metrics.json` 中的 Precision、Recall、mAP50 和 mAP50-95，不把验证集指标替代测试集指标。

独立测试集共有 88 张图片和 335 个实例，评估使用 640×640 输入、batch 16、置信度阈值 0.25。结果如下：

| 类别 | 实例数 | Precision | Recall | mAP50 | mAP50-95 |
|---|---:|---:|---:|---:|---:|
| keyboard | 208 | 0.943 | 0.894 | 0.967 | 0.754 |
| nongfu_spring | 25 | 0.611 | 0.920 | 0.835 | 0.726 |
| phone | 102 | 0.819 | 0.712 | 0.790 | 0.611 |
| **总体** | **335** | **0.791** | **0.842** | **0.864** | **0.697** |

桌面 RTX 4060 Laptop GPU 上记录的单图平均时间为预处理 0.967 ms、推理 5.556 ms、后处理 0.305 ms。该速度只描述训练电脑上的测试集批量评估，不作为 Jetson FPS 验收数据。错误分析在置信度 0.25、匹配 IoU 0.50 下运行，从 64 张含误检或漏检的图片中按错误分数保存 12 张典型案例，详见 `results/error_summary.json` 和 `results/error_cases.csv`。

Windows 训练电脑另使用 Osmo Action 5 Pro 录制 40.0 秒实时预览视频，输出为 1280×720、15 FPS。视频显示检测框、类别、置信度和完整循环 FPS，并记录到键盘与手机同时检测；白色手机和运动模糊画面中也保留了真实漏检。该视频按要求保留在本机、不上传 GitHub，只用于确认 Windows 端可实时运行。

## 6. 20 件实物验收规则

实物验收固定测试 20 件：键盘 7 件、农夫山泉 7 件、手机 6 件。每次画面只放置一个真实物体，以最高置信度检测的类别作为该件最终预测。完成全部类别配额且正确数不少于 16 时通过。

当前尚未运行实物验收，因此本报告不声明正确率已经达到 80%。

## 7. Jetson 与 ROS2 验收规则

Jetson 程序使用 FP16、640 输入和 0.50 置信度阈值，预热 30 帧后测量完整处理循环 500 帧。完整循环包含摄像头读取、推理、绘图、ROS2 发布和结果写入。正式结果采用 `pytorch_fp16` 或 `tensorrt_fp16` 制品契约；对应 FPS JSON 的 `protocol_matches` 必须为 `true`、`measured_frames` 必须等于 500，且 `mean_fps` 必须不低于 5.0。

ROS2 节点固定为 `task1_yolo_detector`，话题固定为 `/yolo/detections`，消息类型固定为 `std_msgs/msg/String`，内容为 UTF-8 JSON。

使用者已确认 ROS2 节点能够在实机发布 `/yolo/detections`。由于本次没有提交 `ros2 topic echo`、`ros2 topic hz`、JSONL 或 `fps_jetson.json`，报告不填写话题频率和 Jetson FPS，也不声明 5 FPS 验收已通过。

## 8. 结论

仓库的数据、数据审计、YOLO26n 训练、模型发布、独立测试集评估、Windows DJI 实时演示和 ROS2 发布运行已经完成。测试集总体 mAP50 为 0.864、mAP50-95 为 0.697，模型和测试结果可通过 SHA-256 与数据指纹追溯。Windows 视频按要求不上传；20 件实物正确率、Jetson FPS 和 ROS2 频率没有归档证据，因此本报告不填写这些数值。
