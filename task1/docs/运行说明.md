# 运行说明

## 1. 检查数据

仓库已包含 596 张 YOLO Detection 格式图片及标签。训练前运行：

```bash
python src/check_dataset.py --data configs/data.yaml
```

程序返回码为 0 且报告中 `valid=true` 时才应开始训练。缺失标签默认视为背景图片警告；如果数据集不允许背景图，加 `--strict-missing-labels`。

## 2. 训练

`configs/train.yaml` 默认加载 `yolo26n.pt` 的 COCO 预训练参数，再针对键盘、农夫山泉和手机三类物体微调 100 轮。首次运行时 Ultralytics 会自动下载预训练权重。

```bash
python src/train.py --config configs/train.yaml
```

仅检查参数而不训练：

```bash
python src/train.py --config configs/train.yaml --dry-run
```

主要输出：

- `runs/task1_yolo26n/`：Ultralytics 原始训练结果。
- `models/best.pt`：自动发布的最佳权重。
- `models/model_info.json`：模型溯源和校验值。

## 3. 测试集评估

```bash
python src/evaluate.py --model models/best.pt --data configs/data.yaml
```

评估固定使用 `test` 划分，不使用训练集或验证集代替。

## 4. 20 件实物测试

```bash
python src/acceptance_test.py --model models/best.pt --samples 20
```

每次将待测物体置于摄像头前，画面稳定后按真实类别编号。程序保存当帧图片、所有预测、匹配置信度、FPS 和正确与否。建议在不同距离、角度和光照下完成 20 次。

## 5. Jetson 实时检测

见 `Jetson部署说明.md`。

## 6. 故障排查

- `Model does not exist`：先完成训练，或将有效权重放到 `models/best.pt`。
- `Cannot open camera`：检查 `/dev/video*`、摄像头索引和用户的 `video` 组权限。
- CUDA 不可用：检查 JetPack、NVIDIA PyTorch 和 Ultralytics 版本。
- ROS2 导入失败：先执行 `source /opt/ros/<distro>/setup.bash`。
- 远程 SSH 无图形界面：使用 `--headless --save-video ...`。
