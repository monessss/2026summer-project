# 运行说明

训练电脑固定使用 Python 3.10；应用包版本固定在 `requirements-train.txt`。训练电脑先安装与 NVIDIA 驱动匹配的官方 PyTorch，Jetson 运行环境先提供 NVIDIA 兼容表中明确支持当前 JetPack 的 PyTorch/torchvision；两个环境随后安装各自 requirements 文件。Jetson 不安装桌面版 PyTorch。训练程序和 Jetson 程序会记录实际 PyTorch、CUDA、GPU 与 Ultralytics 版本。

Windows 正式训练与测试固定在 `C:\yolo\2026summer-project\task1` 运行。`train.py` 和 `evaluate.py` 会拒绝包含中文字符的 Windows 项目路径，防止第三方图像加载器产生静默读图失败。

## 1. 检查数据

仓库已包含 596 张 YOLO Detection 格式图片及标签。训练前运行：

```bash
python src/check_dataset.py --data configs/data.yaml
```

程序检查图片可解码性、图片—标签配对、标签字段、类别编号、框边界、图片哈希重复和 DJI 连续序列跨集情况。只有返回码为 0 且报告中 `valid=true` 时训练程序才会继续；当前数据集不允许缺失标签。

## 2. 训练

`configs/train.yaml` 固定加载 `yolo26n.pt` 的 COCO 预训练参数，再针对键盘、农夫山泉和手机三类物体微调 100 轮。优化器固定为 AdamW，初始学习率为 0.001，余弦学习率调度开启。首次运行时 Ultralytics 自动下载预训练权重。

正式运行前，`runs/task1_yolo26n` 必须不存在；训练脚本检测到同名目录时直接终止，防止旧实验文件与本次结果混合。

```bash
python src/train.py --config configs/train.yaml
```

仅检查参数而不训练：

```bash
python src/train.py --config configs/train.yaml --dry-run
```

主要输出：

- `runs/task1_yolo26n/`：Ultralytics 原始训练结果。
- `models/best.pt`：自动发布的最佳权重。
- `models/model_info.json`：模型溯源和校验值。

## 3. 测试集评估

```bash
python src/evaluate.py --model models/best.pt --data configs/data.yaml
```

评估固定使用 `test` 划分，不使用训练集或验证集代替。

## 4. 20 件实物测试

```bash
python src/acceptance_test.py --model models/best.pt
```

每帧只放置一个待测物体。按 `0` 记录键盘、按 `1` 记录农夫山泉、按 `2` 记录手机。固定配额为 7、7、6，共 20 件；程序以最高置信度检测的类别判定对错，并保存画面、全部检测、最终预测、置信度和 FPS。完成全部配额且至少正确 16 件时通过。

## 6. 故障排查

- `Model does not exist`：先完成训练，或将有效权重放到 `models/best.pt`。
- `Cannot open camera`：检查 `/dev/video*`、摄像头索引和用户的 `video` 组权限。
- CUDA 不可用：重新安装与当前 JetPack 匹配的 NVIDIA PyTorch wheel。
- ROS2 导入失败：加载本机已安装 ROS2 发行版的 `setup.bash`，确认 `ROS_DISTRO` 已导出。
- 远程 SSH 无图形界面：使用 `--headless --save-video ...`。
